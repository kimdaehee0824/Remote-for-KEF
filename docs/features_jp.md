# 機能の説明

[English](features.md) · [한국어](features_ko.md) · 日本語

Remote for KEFはローカルネットワーク経由でスピーカーと直接通信します。接続と再接続では状態を読むだけで、自分で変えるまでスピーカーの値は何も変わりません。

## 電源と入力

- スピーカーをスタンバイにするか、最後の入力または選んだ入力で電源を入れます。
- 電源を入れる前に、音量が上限の範囲内かを確認します。スタンバイ前の音量が上限より高い場合は電源を入れず、理由を表示します。
- 入力ごとに音量が異なる場合があるため、切り替え中はミュートします。切り替え後、新しい入力の音量が前より高くなく上限の範囲内のときだけミュートを解除します。そうでない場合はミュートのままにして、理由を表示します。
- ネットワーク経由で電源を入れられない機器はアプリが知らせるので、リモコンで電源を入れてください。

## 音量

- 0〜100を1刻みで調整します。表示される数値は、常にスピーカーが返した実際の値です。
- フライアウトとパネルからミュートとその解除ができます。

## 音量の上限

上限は2つあり、低いほうが適用されます。

- **アプリの上限**: このアプリが上げる最大の音量
- **KEF機器の最大音量**: KEF Connectで設定した最大音量

適用中の上限は、音量スライダーの目盛りで確認できます。下げる操作はいつでもでき、リモコンやKEF Connectで変えた音量は制限しません。すでに上限より高い場合は、下げることだけができます。

## 正確な音量合わせ

KEFのスピーカーは一部の範囲で、下から上げた音量が同じ数値でも小さく聞こえます。**正確な音量合わせ**をオンにすると、音量を上げるときに少し高い値を先に送り、0.1秒後に目標の値を送るため、上から下げたときと同じ大きさで聞こえます。

- 20に上げると22を経由し、12に上げると17を経由します。
- 5以下と41以上はそのまま送ります。
- 経由する値は上限を超えず、下げるときはそのまま送ります。

この表は、[kef-lsx-volume](https://github.com/roberdorfer/kef-lsx-volume)がLSX II（USB入力）で測った値をもとにしています。LSX II LTではまだ確認していないため、初期設定ではオフです。

## Windows

- **ショートカット**: どのアプリからでも<kbd>Ctrl</kbd>+<kbd>Alt</kbd>+<kbd>↑</kbd> / <kbd>↓</kbd>で音量を、<kbd>Ctrl</kbd>+<kbd>Alt</kbd>+<kbd>M</kbd>でミュートを切り替えます。VS Code、JetBrains IDE、Visual Studio、Wordも一部を使っているため、**設定 → ショートカット**で変更できます。
- **1回押したときの音量**: 1、2、3、5または**体感音量**。体感音量は、音の大きさが均等に増えるよう測っておいた段階（12、15、19、22、25、29 …）に沿って動きます。65より上では4ずつ、12より下では上げると12、下げると0になります。
- **音量表示**: 音量が変わると右下に表示されます。その上でマウスホイールを回しても音量を変えられます。
- **Windows起動時に実行**: サインインすると通知領域で静かに起動します。
- 機器のWebページのパスワードは、このPCのWindowsユーザーで暗号化して保存します。

## macOS

- メニューバーのアイコンの形で、オン、ミュート、スタンバイ、オフラインを区別できます。横に音量の数値も表示できます。
- 設定から**ログイン時に起動**をオンにできます。
- 機器のWebページのパスワードはキーチェーンに保存します。
- 初回起動時に**ローカルネットワーク**へのアクセスを求められます。許可しないとスピーカーに接続できません。

## スピーカーの色

スピーカーは自分の色を知らせないため、設定で仕上げの色を選ぶと、その色でスピーカーを描きます。初期設定はLS60 Royal Blueです。

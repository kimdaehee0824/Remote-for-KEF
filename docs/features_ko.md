# 기능 설명

[English](features.md) · 한국어 · [日本語](features_jp.md)

Remote for KEF는 로컬 네트워크로 스피커와 직접 통신합니다. 연결과 재연결은 상태만 읽고, 직접 바꾸기 전에는 스피커의 어떤 값도 바꾸지 않습니다.

## 전원과 입력

- 스피커를 대기로 끄거나, 마지막 입력 또는 고른 입력으로 켭니다.
- 켜기 전에 음량이 상한 안에 있는지 확인합니다. 대기 전 음량이 상한보다 높으면 켜지 않고 이유를 알려 줍니다.
- 입력마다 음량이 따로일 수 있어서, 입력을 바꾸는 동안 음소거합니다. 전환이 끝나면 새 입력의 음량이 이전보다 높지 않고 상한 안일 때만 음소거를 풉니다. 아니면 음소거를 유지하고 이유를 알려 줍니다.
- 네트워크로 켤 수 없는 기기는 앱이 알려 주며, 리모컨으로 켜야 합니다.

## 음량

- 0~100을 1 단위로 조절합니다. 화면의 숫자는 항상 스피커가 돌려준 실제 값입니다.
- 플라이아웃과 패널에서 음소거하고 풀 수 있습니다.

## 음량 상한

상한은 두 가지이고, 낮은 쪽이 적용됩니다.

- **앱 상한**: 이 앱이 올리는 최대 음량
- **KEF 기기 최대 음량**: KEF Connect에서 정한 최대 음량

적용 중인 상한은 음량 슬라이더의 눈금으로 보입니다. 내리기는 언제나 되고, 리모컨이나 KEF Connect로 바꾼 음량은 제한하지 않습니다. 이미 상한보다 높으면 내리기만 할 수 있습니다.

## 정확한 음량 맞추기

KEF 스피커는 일부 구간에서 아래에서 올라온 음량이 같은 숫자인데도 더 작게 들립니다. **정확한 음량 맞추기**를 켜면 음량을 올릴 때 조금 높은 값을 먼저 보내고 0.1초 뒤 목표 값을 보내서, 위에서 내려온 것과 같은 크기로 들리게 합니다.

- 20으로 올리면 22를 거치고, 12로 올리면 17을 거칩니다.
- 5 이하와 41 이상은 바로 보냅니다.
- 중간 값은 상한을 넘지 않고, 내릴 때는 그대로 보냅니다.

이 표는 [kef-lsx-volume](https://github.com/roberdorfer/kef-lsx-volume)이 LSX II(USB 입력)에서 잰 측정값을 바탕으로 합니다. LSX II LT에서는 아직 확인하지 않아 기본으로 꺼져 있습니다.

## Windows

- **단축키**: 어느 앱에서든 <kbd>Ctrl</kbd>+<kbd>Alt</kbd>+<kbd>↑</kbd> / <kbd>↓</kbd>로 음량을, <kbd>Ctrl</kbd>+<kbd>Alt</kbd>+<kbd>M</kbd>으로 음소거를 바꿉니다. VS Code, JetBrains IDE, Visual Studio, Word도 일부를 쓰므로 **설정 → 단축키**에서 바꿀 수 있습니다.
- **한 번 누를 때 음량**: 1, 2, 3, 5 또는 **체감 음량**. 체감 음량은 소리 크기가 고르게 늘도록 미리 잰 단계(12, 15, 19, 22, 25, 29 …)를 따릅니다. 65 위에서는 4씩, 12 아래에서는 올리면 12, 내리면 0으로 갑니다.
- **음량 표시창**: 음량이 바뀌면 오른쪽 아래에 나타납니다. 그 위에서 마우스 휠로도 음량을 바꿀 수 있습니다.
- **Windows 시작 시 실행**: 로그인하면 알림 영역에서 조용히 시작합니다.
- 기기 웹 페이지 암호는 이 PC의 Windows 사용자 계정으로 암호화해 저장합니다.

## macOS

- 메뉴 막대 아이콘의 모양으로 켜짐, 음소거, 대기, 연결 끊김을 구분하고, 옆에 음량 숫자를 표시할 수 있습니다.
- 설정에서 **로그인 시 실행**을 켤 수 있습니다.
- 기기 웹 페이지 암호는 키체인에 저장합니다.
- 처음 실행할 때 **로컬 네트워크** 접근을 묻습니다. 허용하지 않으면 스피커에 연결할 수 없습니다.

## 스피커 색상

스피커는 자기 색을 알려 주지 않으므로 설정에서 마감 색상을 고르면 그 색으로 스피커를 그립니다. 기본값은 LS60 Royal Blue입니다.
